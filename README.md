# AST-based Tuberculosis Classification

This project explores the use of the Audio Spectrogram Transformer (AST)
for cough-based Tuberculosis (TB) classification using Stratified Cross Validation evaluation.

## Acknowledgement

This repository is adapted from the original AST (Audio Spectrogram Transformer)
implementation proposed by Yuan Gong, Yu-An Chung, and James Glass
in the Interspeech 2021 paper.

Original repository:
https://github.com/YuanGongND/ast  

Paper Publication:
https://arxiv.org/abs/2104.01778


---

## Overview

- Model: Audio Spectrogram Transformer (AST)
- Task: Tuberculosis Classification
- Evaluation Method: 5-Fold Cross Validation
- Metrics: AUC , F1 , Accuracy, Sensitivity , Specificity
